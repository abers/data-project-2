Installing packages

Which command installs the readxl package?

NoteSolution

Use install.packages("readxl") to install the package. The package name must be string, so needing surrounding quotation marks "readxl". library(readxl) is a correct R function, but loads an already-installed package.

Fix the error

This code should load the package for reading Excel files - but is returning an error when run. Run it, read the error message, and correct the code.

TipHint

Which package provides functions for working with Excel files? read_excel() is a function provided by the package we need, but library() needs the name of the package we installed.

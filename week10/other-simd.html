Below are various other datasets that should be linkable with the SIMD. Note, I have not tested these all. As seen in the two examples covered on other pages, linking SIMD can be straight forward if the something like the data zone column value are direct match in both data sets. However, as also seen, sometimes the column in one can be slightly different to the other, where may need to first modify the column in one data set so they can be joined.

Covered in examples for this week

  • Scottish Government Domestic Energy Performance Certificates - Dataset to Q3 2026 (we only used a few of the files but there are a lot more files)
  • Ordnance Survey OS Open Greenspace (we only used the parks and gardens data, but it includes a lot more)
